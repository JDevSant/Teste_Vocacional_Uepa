# Estrutura do projeto

## `index.html`
É o ponto de entrada do site. Deve ser usado para alterações de estrutura e conteúdo visual da página.

## `css/style.css`
Arquivo responsável pela identidade visual.

Principais grupos de estilos:

- variáveis de cor e configurações gerais;
- cabeçalho e navegação;
- Home;
- seção de funcionamento;
- perfil;
- cards dos cursos;
- questionário;
- tela de resultado;
- modal;
- responsividade para telas menores.

## `js/data.js`
Arquivo de conteúdo do teste. É onde devem ser feitas alterações em perguntas, respostas, cursos, descrições e pesos.

## `js/app.js`
Arquivo de comportamento. Manipula o DOM e executa as ações do usuário.

## `assets/`
Guarda as imagens utilizadas pelo site.

## `docs/`
Documentação complementar para manutenção e entendimento do projeto.
